# ecom

Cada marca tiene su propia carpeta, con su landing y su tienda.

| Carpeta | Marca | Qué es |
|---|---|---|
| `VANTA-zapatillas/` | **VANTA** | Zapatillas urbanas · negro y blanco |
| `ORDI-organizacion-hogar/` | **ORDI** | Organización inteligente del hogar · lino y grafito |

Dentro de cada una:

- `landing/` → landing del producto (`*-landing-snippet.txt` para pegar como snippet en Shopify),
  `landing-*-shopify.html` para verla con doble clic, e `info.txt` con ofertas, instalación y pendientes.
- `tienda/` → secciones de Shopify: inicio, catálogo, contacto, pie de página, el snippet
  `icon-discount` y `vista-previa-inicio.html` para ver el inicio en el navegador.

La landing original de VERDEA está en la rama `claude/verdea-landing-setup-ns13rh`.
